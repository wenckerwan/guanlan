考生路径

一般认为，在重力的作用下，当树叶飘离枝头坠落地面时，密度大的叶片正面更容易朝下着地。科学研究表明，叶片的下落过程并非简单的直线下落，因为叶片形状并非完全对称，加之空气阻力、涡流和风等因素的影响，叶片以翻滚和旋转的复杂运动形态下落。内部结构差异与外在形态变化在一定程度上影响着叶片的飘落状态，旋转动能和空气阻力也是影响叶片在下降过程中朝向的因素。叶片下落的过程表明，事物运动的规律（ ）

  1. A取决于外在因素作用的大小
  2. B是纯粹偶然因素作用的结果
  3. C取决于物质形态变化的规律
  4. D是各种因素相互作用的结果
参考答案D据题册校核

本题难点：须从较长科学材料抽取多因素关系，并区分单因、偶然和综合作用。

考生路径

考生视角：进入题目之后怎样做

长材料先划“并非简单直线”“形状不对称”“空气阻力、涡流、风”“相互影响”，不计算物理量。设问对象是运动规律的形成与体现，不是“这片叶子最后哪面朝下”。将材料压缩为：运动结果涉及内部结构与外部条件，多种作用共同发生。D能够覆盖这组信息。

排A时要说明它把复杂过程缩成外在因素的大小；排B时要说明它把有规律的过程归为纯偶然；排C不能只因为绕口便删除。C把需要说明的运动规律归到“物质形态变化的规律”，没有抓住材料呈现的多因素关系，属于用抽象套抽象的解释。本题不要求证明所有自然规律都以同一种因果模型产生。

考生路径

犹豫与误选分叉

会背“内因决定、外因条件”的考生可能急于把题面塞进该公式，再寻找写“内部”的选项，反而无所适从。这里先识别题目实际提供的选项：D不是否认内因与外因的区别，而是针对落叶运动强调多种因素的客观作用。不能为了用上最熟的口诀，忽略设问层级。

命题构造

命题结构：材料、设问、选项为什么这样配合

材料用日常观察引入，再用研究结果修正“只看重力”的简单解释。重复出现的形态、结构、空气作用把考生引向联系的多样性与条件性。推断其区分功能在于：能否从复杂现象抽取关系结构，而非停留在“科学材料很难”或“凡是科学就选规律客观”。

命题构造

四项组合的功能

A是单因化解释，B是偶然化解释，C是未经材料支持的概念转套，D是综合作用解释。四项争论的是“怎样解释”，不是四个物理术语谁更专业。D中的“各种因素”在这里指材料所讨论的相关因素，并不意味着世界上任意两个因素都直接作用于这片叶子。

复习要点

易错提醒

材料中的内外因素都有作用，不能只见重力就归为外因决定，也不能将复杂运动直接说成纯粹偶然。

03单选难度4/5从兵法的灵活应变，跨到自由与必然
原题PDF 225

《孙子兵法》将变化视作军事运行的常态，认为“兵无常势，水无常形”，要使战争主动权始终掌握在自己手中，就要根据不同的情况灵活应对。由此可知，“兵无常势，水无常形”契合了（ ）

  1. A“原则是研究的出发点”的观点
  2. B“理性是衡量一切的唯一尺度”的观点
  3. C“意志自由只是借助于对事物的认识来作出决定”的观点
  4. D“思维的本质在于把意识的因素联合为一个统一体”的观点
参考答案C据题册校核

本题难点：需要从兵法应变跨到自由与必然，正确项不是题干关键词的直白重复。

考生路径

考生视角：进入题目之后怎样做

“兵无常势、水无常形”很容易激活“运动、变化、矛盾特殊性”。先不急着给材料贴一个最终标签，读完“根据不同情况灵活应对”及四个观点。真正待连接的是：在变动条件下怎样作出自主而正确的决定。C的“借助对事物的认识作决定”给出了从客观情势到决策的桥梁。

把“自由”译成“认识条件和规律之后形成自主行动”，就能看到C不是突然跳来的另一章术语。自由不等于无约束、不等于任性，也不是只靠认识而不需要实践。材料的行动环节是灵活应对，认识环节是把握不同情况。

考生路径

犹豫与误选分叉

熟悉辩证法却不会跨范畴映射的人，可能因选项没出现“具体问题具体分析”而乱选；另一类人见“理性”便选B，以为战争决策当然靠理性。B把理性设为唯一尺度，弱化客观事实与实践检验。A把原则直接作为研究起点，也不能替代从实际情况出发；D谈思维内部的联合统一，没有回答对客观情况的认识如何支持行动。

命题构造

命题结构：材料、设问、选项为什么这样配合

题面没有明写“自由与必然”，正确项也不是最直白的同义词。这种构造可推断是在检查概念的功能理解：考生能否将一段军事决策过程映射到哲学关系。古籍承担情境，不要求背作者生平或句子出处；把握行动机制足以进入题目。

命题构造

四项组合的功能

A偏向先定原则，B偏向唯一理性尺度，C强调认识对象后决策，D偏向思维内部统一。若仅按“哪个句子像名言”选择，四项都具有迷惑性。不要仅凭本题给A、B、D的原句作者或思想传统贴未经核实的标签：当前任务是判断它们与此材料的契合程度。

复习要点

易错提醒

自由不是任意摆脱规律，而是在认识客观条件和规律的基础上自主决策、开展实践。没有出现熟悉口诀时，要寻找相同的关系。

04单选难度3/5趋势能判断，具体进程有边界；同题两种不同错误
原题PDF 225

列宁在谈到未来社会时写道：“我们可以绝对有把握地说，剥夺资本家一定会使人类社会的生产力蓬勃发展。但是，生产力将以什么样的速度向前发展，将以什么样的速度发展到打破分工、消灭脑力劳动和体力劳动的对立、把劳动变为‘生活的第一需要’，这都是我们所不知道而且也不可能知道的。”这段话表明，对未来社会可以预见的是（ ）

  1. A生产力发展的具体方式
  2. B生产力将有更大的发展
  3. C劳动成为生活的唯一需要
  4. D每个人获得无差别的全面发展
参考答案B据题册校核

本题难点：同时区分宏观趋势与具体进程，并识别第一/唯一、自由全面/无差别的偷换。

考生路径

考生视角：进入题目之后怎样做

把引文分为肯定句和限制句：肯定生产力将蓬勃发展；限制对具体速度、阶段进程的预先描述。问的是“可以预见的”，先找肯定句直接覆盖的B。再看其他项的错误性质，不能把三项都归为“未来不知道”。

A要求具体方式，超出该段能肯定的范围；C把“第一需要”改成“唯一需要”，属于内容偷换；D把“自由而全面发展”改成“无差别的全面发展”，同样是概念错误。人的自由而全面发展包含个性、能力和活动范围的丰富，不能读成所有人同质化。

考生路径

犹豫与误选分叉

知道共产主义追求人的全面发展的考生，可能只识别“全面发展”四字，忽略“无差别”。也可能看见引文中的“第一需要”，就把C当近义改写。这两种错误都来自只扫核心名词。另一个误区是把“不能预定具体进程”扩大成“任何具体未来现象永远不可能作科学预测”，这也超出本题。

命题构造

命题结构：材料、设问、选项为什么这样配合

B保持宏观趋势，A上升为具体设计，C、D在熟悉概念前加入错误限定。正确项和干扰项不处于同一种错误轴线上，题目可以同时检查科学预见的边界与固定概念的完整性。推断其诊断价值在于：答错D的人可能不是不懂预见边界，而是误读人的发展目标。

命题构造

四项组合的功能

A是“趋势→细节”过度推演；B是引文明确肯定的概括；C是“优先性→排他性”偷换；D是“全面与自由→统一无差别”偷换。题册PDF234把D称为共产主义高级阶段特征的解释有误，应修正这一解释，不能用它给D提供正确概念基础。

复习要点

易错提醒

劳动的“第一需要”不等于“唯一需要”；人的“自由而全面发展”不等于同质化、无差别发展。对未来趋势的科学判断不等于预定全部细节。

05单选难度2/5“解剖麻雀”怎样从操作方法指向研究目的
原题PDF 225

毛泽东同志在谈到中国革命经验时指出：“党的领导机关，包括全国性的、省的和县的负责同志，也要亲自调查一两个农村，解剖一两个‘麻雀’。这就叫作解剖学。”毛泽东在此强调“解剖麻雀”的实际意义在于（ ）

  1. A理论只有彻底，才能说服人
  2. B反对经验主义、尾巴主义和机会主义
  3. C没有革命的理论就不会有革命的实践
  4. D全面深入了解本国实际，发现本国革命的规律
参考答案D据题册校核

本题难点：调查动作与研究目的能够直接对应；其他项主要是邻近但不合题意的表述。

考生路径

考生视角：进入题目之后怎样做

圈出“亲自调查一两个农村”与“实际意义”。操作是研究典型，目的不是数村庄、不是证明理论很彻底，而是深入掌握本国实际并发现规律。D把方法和目的连起来。考场上可以搭一个三步结构：个别典型→深入具体实际→认识本国革命规律。

这个结构还含一个隐含限制：典型调查不能自动替代所有地区的实际，更不能把一个样本的结论机械推广。材料说“全面深入了解”指研究的目标和深入性，不是仅查两个村就完成全国每个角落的实地调查。

考生路径

犹豫与误选分叉

熟记“没有调查，没有发言权”的考生可能很快选D；熟记许多革命理论格言的人可能在A、C上停留。A谈理论说服力，C谈理论与革命实践的关系，都缺少题面最突出的“调查本国实际”环节。B是若干思想倾向的名称组合，材料并未围绕这些倾向逐个展开，不应被其政治词汇密度吸走。

命题构造

命题结构：材料、设问、选项为什么这样配合

材料使用具体比喻，设问要把比喻翻译为方法论效果。推断其区分功能是检查能否辨认一段话在整个理论系统里的工作环节，而非看见毛泽东就调用任何正确的革命理论。本文不把三个干扰项一律标为“内容永远错误”，尤其要区分“不回答本题”与“完整句子是否严谨”。

命题构造

四项组合的功能

A把目的换成理论彻底性，B换成反对思想倾向，C换成理论先导关系，D保留调查、实际与规律。关键词都有关理论与革命，只有D承接了题面的具体动作。对“实际意义”的回答应有“做这种调查能获得什么”，不能只表态“调查很重要”。

1987年3月25日，邓小平在审阅《关于草拟十三大报告大纲的设想》时，对于《设想》提出党的十三大报告全篇拟以社会主义初级阶段作为立论的根据作出批示：“这个设计好。”《设想》的设计思路好就好在，它（ ）

  1. A系统阐明了社会主义与共产主义的关系
  2. B提出我们的社会主义制度还处在社会主义初级阶段
  3. C明确了社会主义初级阶段是我们制定路线方针政策的出发点和根本依据
  4. D明确了发展生产力是社会主义现代化的根本任务
参考答案C据题册校核

本题难点：多个相关表述同题出现，须区分阶段结论、政策根据和建设任务。

考生路径

考生视角：进入题目之后怎样做

读题先保留“1987年”“十三大报告”“全篇以社会主义初级阶段作为立论根据”“好就好在”。任务是说明报告结构为什么这样设计。C把“初级阶段”连到路线方针政策的出发点和根本依据，直接解释立论根据的功能。

B讲提出一个判断，C讲让这个判断统摄政策设计。若只回答“它提出初级阶段”，就少了“为什么全篇都围绕它”的论证。D讲根本任务，属于在既定阶段判断下要做的事，仍不是立论起点本身；A转到社会主义与共产主义关系，设问没有要求这一概念关系。

考生路径

犹豫与误选分叉

B最容易成为残留候选，因为它和题干出现相同名词。此时要把“是什么判断”和“为什么用该判断作根据”分开。题面也不宜被改写成“十三大第一次出现初级阶段的任何认识”：本题不要求对“第一次提出”作历史判定，不能为了排B硬加未经验证的首次叙事。

命题构造

命题结构：材料、设问、选项为什么这样配合

材料给出了报告编写情境，使考查不只是背一条阶段理论，而是理解理论在政策组织中的功能。可观察的差异是A关系、B事实判断、C政策根据、D建设任务四个层级。推断其区分度来自层级对应，更多背同一段教材并不必然解决“最符合”的判断。

命题构造

四项组合的功能

A换了理论关系对象；B保留阶段结论但没有解释立论作用；C给出根据到政策的连接；D保留阶段内的重要任务，却把结果层挪到依据层。排项不需要将D“发展生产力是根本任务”本身说成错误。

复习要点

易错提醒

问“立论根据”的意义，选政策制定的出发点与根本依据；问“根本任务”，才转到发展生产力。正确知识也可能不回答本题。

07单选难度1/5制度层级题：统领、根本、基本怎样避免混用
原题PDF 226

中国特色社会主义制度是党和人民长期实践探索形成的，既具有社会主义的性质，又吸收了古今中外制度建设的有益成果。它是一个严密完整的科学制度体系，其中有统领地位的是（ ）

  1. A民族区域自治制度
  2. B党的领导制度
  3. C社会主义基本经济制度
  4. D全过程人民民主制度
参考答案B据题册校核

本题难点：统领地位对应党的领导制度，核心是固定制度层级定位。

考生路径

考生视角：进入题目之后怎样做

长题干先压缩为“在制度体系中居统领地位的是什么”。这里决定答案的是“统领”，不是“哪一制度重要”。党的领导制度对应B。即使熟悉民族区域自治、基本经济制度和全过程人民民主，也不能用熟悉程度代替层级判断。

可将题目画成一个简图：领导统领体系，其下不同领域制度分别发挥各自功能。图用于理解关系，不意味着所有制度可以仅按高低排成一条线；根本政治制度、基本政治制度、基本经济制度分别有具体分类语境。

考生路径

犹豫与误选分叉

见“社会主义性质”便选C，是把经济基础知识硬套进制度层级；见“人民”便选D，是把价值主体或民主形式套进统领地位。另一种误判是将“人民代表大会制度是根本政治制度”记成“凡问最高都答人大”。本题没有人大选项，也没有问根本政治制度。

命题构造

命题结构：材料、设问、选项为什么这样配合

四项都位于制度话语内部，材料几乎不需要外部事实推导。可推断这是一道术语精度与层级归类题；政治表态正确并不能自动给出正确层级。长背景降低不了那个单词的决定性，也不能把全部背景都当无用信息：它界定讨论的是中国特色社会主义制度体系。

命题构造

四项组合的功能

A是基本政治制度之一，B是领导制度，C是基本经济制度，D涉及民主制度安排。命题把跨领域的相关对象并列，检查考生是否把“根本领导制度”“根本政治制度”等固定表述拆开记住。

复习要点

易错提醒

统领制度体系的是党的领导制度；根本政治制度、基本政治制度和基本经济制度各有具体分类，不能互换。

08单选难度1/5公共安全治理的转型：提炼轴线，而非选“更强”的措施
原题PDF 226

  1. A从分散管理为主转向单一管理为主
  2. B从政府监督为主转向市场监督为主
  3. C从事后处置为主转向事前预防为主
  4. D从危机疏导为主转向危机干预为主
参考答案C据题册校核

本题难点：治理转型方向属于明确政策表述，材料和选项没有复杂迁移。

考生路径

考生视角：进入题目之后怎样做

问句明确是公共安全“治理模式转型主要指”。观察每项的“从……转向……”：A改管理结构，B改监督主体，C改风险治理时间，D改危机操作方式。题目的固定转型轴是事后处置到事前预防，选C。

判断C不意味着事后处置可以取消。把重心前移，是通过识别、预警和防范减少风险发生；已经发生的危机仍须依法处置。考场里要防止自己把“主要方向”再推成“只有预防”的排他性结论。

考生路径

犹豫与误选分叉

D的“危机干预”听起来比“疏导”强，容易让考生按政策力度排序；A的“单一管理”听起来像统一协调，也会吸引只凭一般管理印象的人。两种路线都没有回答题目所指的既定转型方向。B则把市场监督挪作公共安全治理的主体转换，概念场景不匹配。

命题构造

命题结构：材料、设问、选项为什么这样配合

题目用四种不同轴线构造平行句。推断它检查“从哪一维发生转变”的识别能力；四项句式一样，政策词都不陌生，句式工整并不提供正确性。题干信息不足以从常识演绎出唯一政策表述，遇到记忆缺口应承认其事实基础，不把答对包装成完全无需学习的逻辑推理。

命题构造

四项组合的功能

A结构轴、B主体轴、C时间轴、D处置手段轴。C属于政策规定的主要方向，其他轴不是本次转型的对应表达。正确解释不能只说“预防比治疗好”，还要明确题目考的是这一公共安全政策表述。

复习要点

易错提醒

从事后处置转向事前预防是重心前移，不是取消事后处置。不要把统一协调误记成单一主体管理。

考生视角：进入题目之后怎样做

10单选难度1/5历史转折的“性质改变”，怎样避免瞬间完成叙事
原题PDF 226

1840年，英国发动的鸦片战争以清政府的失败而告终。此后，西方列强通过一系列不平等条约在中国攫取大量特权，中国历史的发展因此发生重大转折，这主要表现为（ ）

  1. A中国出现资本主义因素
  2. B中国社会性质发生改变
  3. C地主阶级退出历史舞台
  4. D清朝统治集团发生分化
参考答案B据题册校核

本题难点：鸦片战争与中国社会性质开始变化，是基础历史节点的直接对应。

考生路径

考生视角：进入题目之后怎样做

看清三个限制：鸦片战争、不平等条约和大量特权、中国历史发展的重大转折。它们共同指向国家主权和社会结构改变，B对应社会性质开始发生变化。可以用“独立封建国家→开始沦为半殖民地半封建社会”定位，不能写成1840年某一天整个转变已全部完成。

原题PDF 226

  1. A国民党的主要军事力量基本上被摧毁
  2. B中国革命重心已经从农村转向城市
  3. C延续22年之久的国民党统治已经覆灭
  4. D人民解放军立刻转入全国性反攻的形势已经成熟
参考答案A据题册校核

本题难点：须区分战略反攻、三大战役、重心转移和南京解放四个相邻节点。

考生路径

考生视角：进入题目之后怎样做

先把“三大战役结束”作为时间锚点。A说主要军事力量基本被摧毁，与战略决战成果对应；D的全国性反攻已在此前展开，不能放在决战结束后才准备发生；B工作重心转向城市的部署在七届二中全会；C反动统治覆灭对应后来的南京解放。

犹豫与误选分叉

命题结构：材料、设问、选项为什么这样配合

原题PDF 226

1992年邓小平南方谈话和党的十四大召开后，我国的现代化建设事业进入从计划经济体制向社会主义市场经济体制转变的新阶段。这一阶段，建立社会主义市场经济体制的中心环节是（ ）

  1. A价格体制改革
  2. B财政制度改革
  3. C国有企业改革
  4. D流通体制改革

本题难点：中心环节依赖历史政策定位，理解市场主体机制能够辅助回忆。

考生路径

考生视角：进入题目之后怎样做

题干指定1992年之后建立社会主义市场经济体制的阶段，问“中心环节”。如果记得固定表述，C可直接定位；如果记忆不稳，先想市场体制需要什么微观主体：企业要能够自主经营、承担经营结果，国有企业改革关系这一基础。机制解释能够支持C，但不能替代所问的历史政策表述核对。

考生路径

犹豫与误选分叉

A是常见直觉候选：市场意味着由市场定价。犹豫点在“必要配套”和“中心环节”的区别。B容易吸引把政府与市场关系理解成只改政府财政的人；D容易吸引把市场理解成销售流通的人。若四项都像对，说明还没有把作用层级锁定。

命题结构：材料、设问、选项为什么这样配合

四项都是真实改革领域，正确项由特定阶段的制度部署决定。推断其功能是检查固定定位和制度机制能否结合。不能把本文的机制推理装成“任何时候建立任何市场体制，企业改革必然都是同一个中心环节”的普遍定理。

命题构造

四项组合的功能

第一问：从读材料到可以写出的关系链

  1. 分清计量单位。 技术构成是生产资料与劳动力的实物关系，由技术水平决定；价值构成是不变资本c与可变资本v的价值关系。实物“量”的配比和货币价值配比不是同一个数字口径。

参考作答 教学整理

（1）新民主主义革命取得民族独立和人民解放，为发展生产、实现工业化创造政治前提；材料1说明革命的目标同国家发展相联系。新中国工业化和社会主义建设要求发展生产力、巩固物质基础，正确探索及曲折教训表明建设必须尊重规律并重视经济发展。改革开放作出把工作中心转到经济建设的历史性决策，回应国情与人民需求。经济建设为其他事业提供物质基础，坚持这个中心同时须推进全面建设，不能单打一。

（2）中国式现代化坚持马克思主义基本原理并结合中国实际与时代条件，发展了对现代化道路的认识。人口规模巨大要求从具体国情组织发展；共同富裕坚持社会主义方向和人民立场；物质精神协调深化全面发展理解；人与自然和谐共生把生态关系纳入发展道路；和平发展探索通过合作推进现代化的新选择。这些内容将原理转化为中国实践方案并形成新的理论认识，推进马克思主义中国化时代化。

本题难点：跨革命、建设、改革材料，还须把现代化特色连接到原理、国情和理论增量。

考生路径

考生视角：先回答“为什么强调”，再处理“如何推进”

第一问限定新民主主义革命和社会主义建设道路的探索过程，问为何强调以经济建设为中心的现代化建设。材料1是1945年政治条件与工业化设想，材料2是1980年经济中心与物质基础，材料3是中国式现代化丰富内涵。读完问句，应将材料1、2主要用于第一问，材料3主要用于第二问，同时保留历史过程与理论关系。

第一问不能写成“新民主主义革命时期党的工作中心已经始终是经济建设”。当时需要首先完成反帝反封建等革命任务、取得政治条件，为建设创造前提。把后来建设中心无条件前置，是本题最需要防范的历史压缩。1945年材料明确“在新民主主义政治条件获得之后”，这句限定应进入判断。

考生路径

第一问：把三种理由串成历史解释

政治前提与发展目的。 革命不是仅为更换统治者，取得解放与新的政治条件，是为了使人民和国家能够发展生产、推进工业化。材料1把政治条件与工业化衔接，说明革命任务和建设目标相联系，而不是两者混同。

建设探索的经验。 新中国工业化与社会主义建设需要发展生产力、巩固经济基础。建设时期有正确探索，也有受“左”倾错误影响的曲折；党的八大等正确判断不能从叙述中删除。改革开放把工作中心转到经济建设，是基于国情与正反经验，不应写为1980年讲话第一次使党想到发展经济。

现实国情与现代化要求。 经济建设提供其他事业赖以发展的物质基础，我国发展阶段和人民需求要求继续解放发展生产力。材料2强调其他任务围绕中心，并非否认文化、政治、社会和生态建设；中心是组织发展任务的着力点，不等于单打一。

写作时三个块分别回答革命为何通向建设、建设探索为何需要守住经济中心、当前现代化为何仍需物质基础。若只串年份与人名，没有这三条理由，就只是年代叙述。

考生路径

第二问：五个特色怎样成为理论增量

问句不是“列举中国式现代化五个中国特色”，而是“丰富内涵如何推进马克思主义中国化时代化”。需要先说明基本原理与中国具体实际、时代条件相结合，然后用具体内涵展示理论如何被发展。

题面内涵 可以连接的理论问题 答卷需要说明的增量

考生路径

犹豫与失分分叉

全时间抹平： 把革命、建设、改革三个时期写成始终同一工作中心，会错置历史任务。只记错误： 建设初期只有“左”的失误，没有正确工业化探索，会丢掉完整历史经验。概念名词堆砌： 两个结合、理论创新、实践创新、人民立场全部出现，却无法举一条特色如何联系理论，仍未完成第二问。

另一个分叉是把第二问写成中国式现代化“证明马克思主义不需要再发展”。实际上问的是结合与推进，不能用既有理论自足取消实践形成的新认识，也不能用创新取消基本原理的指导。

命题构造

从命题结构看：跨时期材料承担不同论证功能

可观察的三份材料分别给出目标、中心与道路内涵，问句把它们转成历史理由和理论发展。推断它检查从历史行动中理解理论如何与实际结合，而不是谁先说过哪一句话的识记。材料1中的政治条件限制、材料2中的不能单打一、材料3中的共同特征与中国特色，都能限制套话的扩张。

原题PDF 232

结合材料回答问题：

习近平总书记强调：“一个有希望的民族不能没有英雄，一个有前途的国家不能没有先锋。”

2025年7月21日，第十五届全国见义勇为英雄模范表彰大会，隆重表彰了60个见义勇为英雄模范个人和群体。其中，8名个人和2个群体获“全国见义勇为英雄”称号，40名个人和10个群体获“全国见义勇为模范”称号，被表彰的英雄模范来自各行各业，有工程师、保安、电工、军人、渔民，有人是00后，有人已经退休。据统计，党的二十大以来，全国依法依规确认见义勇为行为超过3万例、见义勇为人员近4万人，其中因见义勇为牺牲人员近500人、致伤致残人员近700人。一人兴善，万人可激，我们看到向善之光、浩然正气在不断汇聚。

为弘扬正气、让善行无惧、使见义勇为者在不必蒙受损失的同时，拥有足够的正反馈，需要发挥法治的力量，为此，民法典第一百八十三条、第一百八十四条，除了规定见义勇为者自身权益受侵害时的保障措施，还规定“因自愿实施紧急救助行为造成受助人损害的，救助人不承担民事责任”。刑法为善行义举“兜底”，其中第二十条关于正当防卫的规定在法律实践中持续落到实处，为见义勇为者撑腰，让施救者有底气。全国人大常委会2025年度立法工作计划将见义勇为人员奖励和保障法纳入预备审议项目，多地各部门也不断修订完善见义勇为的行为认定、奖励和保障制度，为行义举的人们提供更全面系统的支持。

摘编自《人民日报》（2025年7月25日、8月1日）、《光明日报》（2025年8月2日）

（1）营造良好的社会风尚，为什么要弘扬见义勇为精神？（5分）

（2）弘扬见义勇为的精神，法治发挥了什么作用？（5分）

参考作答 教学整理

（1）见义勇为体现关心他人、维护正义和勇于担当，是社会主义核心价值观和中华传统美德的实践。来自各行各业的英雄模范使道德要求具体可感，示范传播能引导社会认同、促进自觉行动，形成互助、信任与崇德向善的社会风尚。

（2）法治把权益保护和责任边界落实为明确规则。民法典183条安排保护他人民事权益而自身受损的责任与补偿，184条依法保障符合规定的自愿紧急救助；刑法正当防卫制度保护依法制止正在进行的不法侵害的行为。认定、奖励和保障制度提供持续支持，依法实施和公正裁判形成明确价值导向、减少后顾之忧，促进道德引领与法律保障相互作用。

本题难点：材料分段为道德意义和法律保障提供了较清楚框架，但条款功能和两问中心仍需区分。

考生路径

考生视角：材料分为榜样段与制度段

第一段写英雄模范来自各行各业、不同年龄，众多义举汇聚社会正气；第二段写权益保护、救助致损责任、正当防卫和奖励保障制度。第一问“为什么要弘扬”要求意义与理由，第二问“法治发挥什么作用”要求制度机制。先在草稿上分别标道德风尚线、法治保障线，再读细节。

第一问可以使用第一段的身份广泛性、榜样性和实践性，说明向上向善、道德建设与核心价值观的作用；第二问重点用法律条款和制度安排解释减少何种顾虑、保护什么权益、确立什么行为导向。将全部统计数字抄两遍，不会自动完成两问。

考生路径

第一问：把“英雄很多”转成风尚形成机制

先说明精神所体现的价值：关心他人、维护正义、勇于担当等是良好社会风尚的重要内容，见义勇为是将价值观落到实际行动的表现。再解释榜样何以能影响社会：英雄来自普通职业和不同年龄，使道德实践具有可感知、可学习的具体形态；表彰传播能够示范和引导，增强认同与行动自觉。最后联系共同生活：人与人之间的帮助和担当有助于形成互助、正义和信任氛围，支持社会道德建设。

这三步回答价值内容、示范传播、社会效果。只写“英雄伟大，所以要表彰”属于循环论证；只写“有几万人见义勇为，所以精神正确”把规模当价值正当性的充分证据。统计数据说明现实存在和广泛性，但不是全部价值论证。

考生路径

第二问：作用如何从具体条款上长出来

材料安排 制度处理的具体问题 可以概括的法治作用
民法典第一百八十三条 因保护他人民事权益而自身受损，怎样安排侵权责任和相应补偿 保护行为人权益，分担符合条件的损失，降低善行后顾之忧
民法典第一百八十四条 自愿紧急救助造成受助人损害时，怎样处理民事责任 依法明确救助责任边界，为符合规定的救助提供保障
刑法第二十条 制止正在进行的不法侵害，何时属于正当防卫 通过责任规则保护合法防卫行为，维护公平正义
认定、奖励与保障制度 义举怎样被确认、支持与救助 形成持续、可执行的制度支持，而非仅靠事后赞扬

法治还通过立法与实施把社会提倡的善行转化为明确规则，通过依法裁判与权利保护形成可预期的行为环境。道德提供价值引领和自觉，法治提供规范、保障和实施机制，二者相互促进。原题问作用，不是要求对一个具体救助或防卫案件作责任判决。

考生路径

容易被参考答案带偏的两处

题册参考把183、184一起概括成“免除紧急救助致损责任”，会混淆自身受损保障与救助致受助人损害的责任规则。本文已按法条区分。另一个风险是把“预备审议项目”写成“当时已经正式生效的全国专门法”。题面只说明2025年立法计划的状态，不能从计划自动跳到制定完成。

正当防卫也有法定条件。不能把“法治为义举撑腰”改成“凡是自认为正义的行为都无条件免责”。刑法第二十条针对正在进行的不法侵害，并对防卫过当与特殊防卫作不同规定；本题只需准确概括保障作用，不需要展开未经给出事实的个案推断。

考生路径

犹豫与失分分叉

道德代替法治： 第二问仍写舍己为人、好人有好报，没说明法律怎样处理权益与责任。法条代替意义： 第一问直接抄183、184，无价值与风尚机制。只写强制力： 把法治理解成处罚坏人，忽略保护、补偿、认定和激励。泛化免责： 从具体条件下的责任规则推出任何救助都无责，增加错误。

这些答卷可能字数很多，仍各缺一个中心环节。更有效的作答，是把一个材料事实转成一个清楚的作用动词：引导、保护、补偿、明确边界、保障实施。

参考作答 教学整理

（1）同舟共济可联系各国命运相连、共同应对风险，体现构建人类命运共同体的合作取向；协和万邦、和而不同可联系平等协商、尊重差异和文明互鉴；共同驾驭航向、协同合作可联系共商共建共享和多领域协调。船喻强调共同责任和合作治理，而非某一国家独自支配或各国利益完全相同。

考生视角：先将两问的对象和动词写出来

第一问“结合中华优秀传统文化，说明以船为喻所蕴含的全球治理理念”，需要文化概念、材料意象、现代治理理念三者相连接；第二问“发展中国家如何影响世界秩序”，需要历史阶段、力量变化、机制与结果。第一问6分、第二问4分，不能按两个同样长的万能外交段平均处理；实际篇幅仍应以任务完成为准。

考生路径

第一问：文化—比喻—治理，三段连接缺一不可

同舟共济与命运共同体。 同一艘船意味着面对共同风险、相互影响，传统互助合作观念可以联系各国共同应对全球挑战。应说各国利益相互联系与责任合作，不写成各国没有任何差异或利益冲突。

协和万邦、和而不同与平等合作。 船上有不同国家和文明，强调共同行动不等于一个国家独自支配方向。可联系主权平等、协商合作、文明交流互鉴、尊重差异；“和而不同”应保留“不同”，不能解释成文化同质化。

共同目标与共商共建共享。 方向、协作、经贸与人文使比喻进入具体治理过程：讨论共同问题、合作提供方案、共同享有成果。它回答如何合作，而非仅说有友好感情。材料中政治、安全、经济、人文不同环节显示合作需要多领域协调。

写作时每一段最好出现一组明确对应。例如“以同舟共济说明全球挑战下各国命运相连，以相互支持、共同协商应对风险，体现构建人类命运共同体的合作取向”。这段同时有文化词、船喻关系和治理含义；只写“同舟共济、天下大同、和而不同”没有完成现代解释。

全球治理倡议的主权平等、国际法治、多边主义、以人为本、行动导向可作为相关框架，但不能将每个船部件硬指定为唯一对应某条原则，也不能将任何传统典故都无条件说成原题明示。原题要求的是有依据的文化解释，不要求编制五个船部件与五条原则机械一一对应。

考生路径

第二问：按力量和机制分阶段，比列一串会议更有解释力

政治觉醒阶段： 二战后民族独立和反殖斗争推动新国家进入国际舞台，要求维护主权、民族平等和自主发展。发展中国家通过团结、协商和国际组织活动争取声音，对殖民体系和大国支配形成冲击，为世界多极化发展提供力量。不能写成它们当时已单独结束两极格局。

共同发展诉求与制度参与： 团结合作使发展中国家能够将贸易、发展和国际经济关系改革纳入多边议程。万隆会议、不结盟运动、七十七国集团等可作经过核对的代表性例子，但每举一个就应说明它在团结、政治自主或经济议程上的功能，而非以组织数量代替机制。

当代群体性崛起： 经济与国际影响力提升，使全球南方成为推动多极化的重要力量；然而力量变化未充分体现在治理体系的代表性和发言权上，由此推动制度与规则改革诉求。通过南南合作、集体协商、多边机制和国际议程参与，争取更公平的代表性和发展机会。题目要求解释这种“力量变化→制度需求→参与改革”的连接。

最后概括它们的影响：推动世界力量分布更趋多元，扩大国际事务参与，促进国际秩序朝更公正合理方向改革。用“推动、促进、争取”的过程词，不写成当今治理已完全公平、发言权已完全均衡或发展中国家具有完全一致的所有立场。
