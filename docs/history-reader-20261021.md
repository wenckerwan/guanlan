# 近现代史会议式阅读页

用户要求：近代史时间轴采用会议专题页的展示形式，并使用蓝色主色调。

## 实现

- 沿用 `/history/` 入口、现有数据仓库、账号隔离和路由参数。
- 蓝色页头、吸顶导航、统计概览、筛选目录、按时间排列的折叠阅读卡片。
- 支持搜索、时期与主题筛选、原表合并组、完整阅读与速记模式、展开和收起、打印。
- 保留日期出处、收藏、笔记、事件对照及学习备份导入导出。
- 不扩写或修改历史事实；无教材定位时继续明确显示原有来源状态。
- 会议专题页和站点全局玻璃主题保持现状。
