- 用户列表从默认最多 50 条改为服务分页，默认 20 条、上限 100 条，返回真实 total/page/perPage。

- 创建账号、编号绑定、用户组/角色/状态修改、密码重置继续保留；之前的最后管理员保护与会话撤销服务保持。

## 接口变更与复验

GET /api/v1/admin/users 返回 `{data:{items,total,page,perPage}}`，旧版返回 `{data:[...]}`。本次更新了后台页面及浏览器测试调用方；上线需将 API 与 Web 配套部署，避免旧页面读取新响应。

参数：q、role、status、userGroup、page、perPage。空筛选表示全部；角色支持 user/admin，状态支持 active/disabled，用户组支持 user/vip/svip/sssvip。非法枚举返回 422，页码及页大小规范化。现有后台权限中间件保持。

无新增数据库迁移。MySQL复验执行 `bash tools/tests/run-admin-reliability.sh`；该脚本运行保护测试和用户列表测试，使用一次性数据库并清理本次容器/网络。

本地浏览器需先 npm run build 并以 NITRO_PORT=3209 启动 `.output/server/index.mjs`，设置 PLAYWRIGHT_MODULE 后执行 `node tools/tests/admin-users-browser.cjs` 及 `node tools/tests/admin-reliability-browser.cjs`。
