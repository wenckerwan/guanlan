## 发现（按建议修复顺序）

### 1. P1：史纲待同步数据可能跨账号提交

- 定位：`apps/web/pages/history/index.vue:68` 构造仓库未传 localName；`components/history/adapters/guanlan-study.ts:35` 默认所有账号共用 `history-study-guanlan-v1`，`:197` 加载待同步状态，`:232` 向当前身份合并。
- 触发：A 登录期间离线保存笔记/收藏，退出后 B 在同一浏览器进入史纲。B 会读取相同的 pending-sync 并使用 B 凭证提交 A 的内容；离线降级读取也共享本地记录。
- 证据：执行真实 GuanlanStudyRepository，经 esbuild 加载，仅替换 IndexedDB 为内存存储、fetch 为测试边界。A 离线保存后新建 B 仓库执行 load，B 返回 A 的笔记和收藏，且发出 PUT favorites、POST notes，正文包含 A private note。没有访问真实账号、数据库或网络；未做浏览器端到端复现。
- 建议：使用服务端确认的稳定 userId 分库，游客单独分区；账号切换销毁旧仓库，旧请求只允许回写原分区；旧共享数据隔离保留，明确归属后才迁移，禁止自动并入下一登录账号。
- 验收：A→离线→退出→B、游客→登录、401→重登、跨标签页切换均不串数据；B 的请求中不出现 A 的笔记或收藏。

### 2. P2：旧用户查询失败会清除新登录

- 定位：`apps/web/composables/useAuth.ts:53`，fetchUser 的 catch 在 `:64` 无条件 persist('', null)，成功路径也未核对请求身份。已有 invalidateToken(expectedToken) 没有在此复用。
- 证据：加载真实 useAuth，模拟旧 /auth/me 请求挂起；先完成新账号 login（token=new），再让旧请求返回 401，最终 token 为空、user=null。仅替换 Nuxt 状态和请求边界。
- 影响：重登录/切换账号过程中可能被旧请求登出；网络故障或 5xx 同样被当成凭证失效。旧成功响应覆盖新 user 的路径也需一并防护，尚未单独运行该变体。
- 建议：捕获请求 token/代次，成功与失败都校验；只有当前身份明确收到 401 时撤销会话，断网和 5xx 提示重试。
- 验收：旧成功、旧401、旧500晚于新登录返回时，新身份保持不变；当前401正确退出，网络失败保留会话。

### 3. P2：无 Key 自定义 AI 配置无法真正分析

- 定位：`apps/api/src/Controller/MistakeController.php:410`、`:488` 无条件 required(apiKey)；`Service/AIAnalysisService.php:1088` 对 custom 允许无 Key；配置输出 `MistakeController.php:827` 也标为可选。
- 影响：连接测试接受的自定义配置，到流式/非流式分析时却被控制器以422拒绝。
- 证据等级：当前源码调用链核对，未运行 PHP HTTP 复现。
- 建议：各入口复用统一供应商规则，保留现有安全出网策略；custom 有合法 endpoint 时 Key 可选，其他供应商按规则验证。
- 验收：连接、对话、两种分析对同一配置的接受/拒绝一致；非法配置不发供应商请求。

### 4. P2：每日“分析次数”实际限制报告保存数量

- 定位：`MistakeController.php:668` 起在保存时统计当天现存报告；两种分析入口没有对应扣减；`:763` 删除报告，保存时另有20份保留清理。
- 影响：不保存仍可反复调用；删报告或自动清理可降低计数；先 count 再 create 也缺少原子额度裁决。这是产品限额与实现不一致，并不表示平台一定承担供应商费用（请求携带用户 Key）。
- 证据等级：当前源码核对，未执行并发或真实供应商调用。
- 建议：先明确限制调用还是保存。推荐独立的每日调用账本、原子预占和 requestId 幂等；明确失败、重试、流式回退是否计次，删除报告不返还调用额度。复用已有练习模块的幂等设计经验，不直接复制其业务表。
- 验收：并发最后一个额度只成功一次；重复请求不重复计次；删除/清理报告不增加额度；拒绝请求不调用模型。

### 5. P2：马原本地存储失败缺少恢复机制

- 定位：`vendor/mayuan/apps/web/app/app.vue:78` 读取或解析失败返回空状态；`:95` setItem 无异常处理，300ms防抖写入。
- 影响：存储禁用/配额耗尽时界面可能已经更新但未落盘；损坏数据被当作空状态，后续保存可能覆盖恢复线索。
- 证据等级：源码核对；没有浏览器模拟配额耗尽。
- 建议：明确显示未保存/只读状态、提供内存状态导出；损坏原值隔离备份，校验导入和迁移；处理页面离开前待保存状态。
- 验收：QuotaExceededError、SecurityError、损坏JSON和离开页面场景有明确反馈与恢复路径。
