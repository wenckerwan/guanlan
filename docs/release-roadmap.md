## V0.1-dev.1：导航与学习入口

目标：让首页和二级菜单真正可用。

- 六大学科页面：马克思主义基本原理、毛泽东思想和中国特色社会主义理论体系概论、习近平新时代中国特色社会主义思想概论、中国近现代史纲要、思想道德与法治、当代世界经济与政治。
- 增加二级菜单、面包屑和返回入口。
- 增加章节卡片和知识点列表。
- 支持移动端导航。
- 修复首页热点推荐跳转。
- 本阶段限定为纯前端静态数据；Hyperf API 和 MySQL 接入放到 V0.1-dev.2。

Git 分支：`feature/subject-navigation`

## V0.1-dev.2：真实内容数据

- 设计政治知识点数据结构。
- 增加 Hyperf 知识点查询 API 并接入 MySQL。
- 首页、学科页和章节页使用 API 数据。
- 增加资料分类、年份、来源字段，并关联本地资料清单。

Git 分支：`feature/content-api`

## V0.1-dev.3：搜索与资料检索

- 接入 Meilisearch。
- 支持知识点、历年真题、时政和资料名搜索。
- 搜索结果高亮，按学科、年份、类型过滤。
- 无结果提示和搜索历史。

Git 分支：`feature/search`

## V0.1-beta.1：学习功能

- 用户注册、登录、邀请码。
- 收藏知识点、学习进度、错题本、学习笔记。
- 每日时政阅读记录和个人学习统计。
- 基础后台管理页。

Git 分支：`feature/study-progress`

## V0.1-beta.2：资料阅读与管理

- 在线 PDF 阅读、页码定位、OCR 文档管理、预览图。
- 文件权限控制，管理员上传/删除文档。
- 文档版本与来源标记。

Git 分支：`feature/document-reader`

## V0.2 稳定版条件

首页、二级菜单和核心页面可用；Hyperf API 与数据库稳定；搜索可用；用户学习记录可用；关键页面已测试；构建部署成功；无阻塞问题；CHANGELOG 完整记录验证结果。

## 后续方向

- V0.3：练习考试、自动组卷、章节测试、错题分析、学习计划、每日打卡。
- V1.0：完整用户系统、后台管理、多端适配、数据统计报告、权限审计、正式部署备份、稳定数据更新机制。

## 固定流程

创建分支 → 开发功能 → 编写测试 → 更新 VERSION → 更新 CHANGELOG → 执行测试和构建 → 检查 git diff → 提交 → 合并 main → 创建 Git Tag。
