# 用户管理 2A 实施计划

基准：main / 5dce800，沿用玻璃主题与账号保护。用户已授权开发，生产部署另行授权。

- [x] MySQL 回归：超过 50 用户的分页/总数、昵称搜索、组合筛选、稳定排序、空结果、超出末页、非法筛选与页大小。
- [x] AdminService.users 返回 items/total/page/perPage，默认 20、上限 100；角色、状态、用户组非法值拒绝，关键词按文字处理。
- [x] 控制器转换资源并返回分页数据；未登录与非管理员路由保护保持。
- [x] 页面筛选状态写入 URL；刷新和返回保留条件；快速切换请求只采用最新响应。
- [x] 共用分页和列表状态组件；加载/错误/空结果区分，错误可重试，不展示伪造零总数。
- [x] 保存后按现有筛选刷新并处理末页回退；保持创建/绑定/用户组/启停/角色/密码重置保护。
- [x] 浏览器验证分页、筛选、URL 刷新、失败重试、快速请求、保存后记录离开筛选与原有确认行为；前端测试/构建、PHP 语法/结构和 MySQL 回归。

接口：GET /admin/users?q=&role=&status=&userGroup=&page=1&perPage=20。页码与页大小规范化，超过末页返回最后有效页；空结果 page=1。关键词不将 % 和 _ 解释为通配符。无效枚举返回 422。旧数组响应改为分页响应，本次同时更新用户页及其浏览器模拟。
