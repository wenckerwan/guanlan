# 观澜视觉重构：搜索页

在 `apps/web` 运行 `npm run build`，再从仓库根目录运行 `node tools/preview-lenso.mjs 3119`。打开 `http://127.0.0.1:3119/search?q=实践与认识`。模拟接口只监听本机；关键词“没有结果”和“请求失败”分别用于查看无结果和失败状态。

在 Edge 验证首页发起搜索、按时政热点筛选、打开文章并返回，搜索词和筛选均保留。暂停本地搜索请求时显示加载提示且隐藏旧列表；也验证了无结果、失败提示及重试重新发起请求。

在 390×844 和 1440×960 下分别检查浅色与深色，搜索结果页无整页横向溢出。截图位于 `output/playwright/lenso-search/`。`npm test` 111 项通过，`npm run build` 成功。未部署或连接生产 API。
