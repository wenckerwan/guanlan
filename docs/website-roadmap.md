## 二、当前已实现（基础功能）

### 前台

- 首页：真实统计条（题量/卷数/热点/预测/分析/错题）、时政热点卡片、六大学科入口。
- 真题回顾：42 卷列表 → 试卷详情 → 逐题作答；`reveal=0` 时服务端不下发答案与解析，
  用于先做题后对答案；支持按模块、题型、年份、关键词检索。
- 真题分析 / 时政热点 / 时政预测：分类列表 + 文章阅读页（目录锚点 + HTML 正文）；
  未登录每个栏目可读 3 篇，其余以锁定卡片展示并弹登录引导，登录后不限额。
- 模拟押题：试卷列表 + 在线作答 + 交卷判分（`utils/quiz.mjs`）。
- 个人错题分析：考生 A 公开可读；模块/章节筛选、错题详情、提分手册阅读；
  私有错题本仅绑定账号与管理员可见，未登录或越权访问回列表并提示登录。
- 站内搜索：`/api/v1/search` 一次聚合七类内容（真题/试卷/分析/热点/预测/模拟/错题），
  支持类型筛选、结果计数与关键词回填。
- 登录 / 注册页；注册即生成递增账号 ID（个人中心可见，交给管理员绑定错题本）；
  未登录访问 `/me/*` 会引导登录。

### 用户态（需登录）

- 收藏（知识点、题目、文章、试卷统一 `targetType + targetId`）。
- 笔记。
- 做题记录与正确率统计（`/study/stats`，可按模块拆分）。
- 阅读进度（`scope + ref`，用于「继续阅读」）。

### 后台（需 `role=admin`）

- `/admin` 总览：内容量、用户数、今日新增、最近注册。
- `/admin/users`：用户列表、角色/状态调整、账号 ID（错题绑定）查看与改绑。
- `/admin/hotspots`：时政热点的增删改。
- `/admin/analysis`：真题分析文章的增删改。

### 基础设施

- 后端 Hyperf 3.1 + MySQL 8.4，统一 `{"data": ...}` 包络、对外字段 camelCase。
- 52 个路由注册（36 GET / 9 POST / 4 DELETE / 3 PATCH），覆盖
  内容只读 + `/auth` + `/study` + `/admin`。
- 19 个迁移、20 个模型、10 个 Service、13 个 Controller、3 个中间件、15 个 Resource。
- 登录态存 Cookie，SSR 首帧即可解析身份，避免游客态闪烁。
- 离线验证：`tools/verify.ps1`（PowerShell，本机可跑）+ `tools/phpcheck.py`（含反向自测）。
- 容器验证：`tools/lint.sh`、`tools/smoke.sh`（在 WSL2 原生副本内跑）。

### 阶段 1：补齐基础功能缺口（V0.1-dev.4）

站点骨架已经可用，这一阶段只补真正的缺口。

| 任务 | 说明 | 完成标准 |
|---|---|---|
| 分页组件 | 真题检索与错题列表目前一次取回 | 列表页有分页控件，URL 带 `page`，刷新后保持 |

## 四、已知限制（当前）

1. **容器未验证**：本机无 Docker Desktop、无 PHP；WSL2 在本环境返回
   `Wsl/Service/E_ACCESSDENIED`，因此本轮的数据库迁移、Seeder、API 冒烟
   **尚未在容器内复跑**。离线侧已用 `phpcheck.py`（含反向自测）覆盖
   PSR-4、括号配平、模型列引用、路由方法存在性四类静态错误。
2. 上一轮遗留的三处修复（`MockQuestion::$timestamps` 类型、
   `ArticleService` 去掉不存在的 `sort_order`、`AppExceptionHandler` 基类）
   已写入代码，**等待容器验证**。
3. 搜索结果用 `LIKE`，数据量继续增长需要换索引。
4. `documents` 表无数据，PDF 阅读未开始。
5. 移动端为响应式降级，未做专属布局。
6. `apps/web` 的 peer 依赖冲突以 `.npmrc` 的 `legacy-peer-deps` 绕过，未真正升级。
