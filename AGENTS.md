# Frontend baseline

- Use `main` and `apps/web` for all future Guanlan frontend work.
- The approved UI is the glass theme deployed on 2026-10-08, introduced by commit `7480150`; keep both `main.css` and `glass.css` loaded.
- Older UI prototypes and release worktrees are archived and must not be used as development or deployment baselines.
- Preserve the existing sections, navigation, and routes unless the user explicitly requests a change.
